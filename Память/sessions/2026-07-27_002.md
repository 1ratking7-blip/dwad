# Сессия 2026-07-27 (002) — "Premium Cinematic Hero", полный редизайн Hero-сцены

## Контекст
Пользователь дал развёрнутое ТЗ (~28 пунктов) в роли "senior UI/UX-дизайнер + арт-директор +
frontend-разработчик premium digital studio": убрать эффект коллажа из четырёх картинок
(машина/карта/деньги/город), собрать единую кинематографичную сцену, добавить процедурно
летящие дизайнерские купюры тремя слоями глубины, обновить типографику/CTA/навигацию/карточки
под новую точную HEX-палитру, проверить на множестве разрешений, довести до продакшн-готовности
самостоятельно (не только предложить, а внедрить и проверить).

## Ветка
`feature/premium-dark-hero` — создана и используется, **не смержена в main, не запушена, не
задеплоена** (пользователь не просил в этот раз — только "премиум сцена", без явного "коммить/
пуш/деплой" как было в прошлом сообщении). 2 коммита: `9ba5174` (доделка забытой правки Память
из прошлой сессии) и `fce8b83` (сам редизайн).

## Что сделано
- **Палитра**: `index.css` `:root/[data-theme='cyberpunk']` переписана на точные HEX из брифа
  (`#020506`/`#050B0A`/`#0B1110` база, `#00C889`/`#008F65`/`#00E89D` изумруд, `#D3B45A`/
  `#A88738`/`#EBD17D` золото, + текстовые/border-переменные). `web3`-тема не тронута.
- **NightSkyline.tsx**: город затемнён через `filter: brightness/contrast/saturate` (не
  opacity — сохраняет глубину чёрного вместо "вымывания" в фон), 2 локальных дрейфующих
  туманных пятна (`.fog-layer-a/b`), лёгкая статичная текстура измороси. Многослойная
  `.luxury-vignette` (3 background-слоя: радиальная + горизонтальная + вертикальная) вместо
  одного плоского radial-градиента — левая часть тёмная под текст, правая светлее под
  машину/деньги, низ плавно уходит в `--color-bg`.
- **Убран эффект коллажа**: `MetalCard.tsx` и его картинка полностью удалены (явно отдельная
  "прямоугольная карточка" рядом с машиной — то, что бриф прямо запрещает). `money-coins.webp`
  тоже удалён — заменён процедурной генерацией (см. ниже).
- **LuxuryCar.tsx**: `mask-image` (радиальный градиент) растворяет прямоугольные края фото в
  сцену вместо видимой рамки; тень контакта колёс + приглушённое затемнение/сатурация фото;
  наклон (`useTilt`) уменьшен до 3° ("почти неподвижен" по брифу). Отражение отдельным
  зеркальным слоем **не добавлено намеренно** — фото машины это цельная сцена (машина+асфальт+
  город), а не cutout с альфа-каналом; зеркалирование всего прямоугольника продублировало бы
  и город тоже, сломав иллюзию вместо укрепления. Компонент теперь абсолютно позиционирован
  внутри `max-w-7xl`-контейнера (а не в grid-колонке) — не уезжает от текста на ultrawide.
- **FloatingWealth.tsx — полностью переписан**: вместо одной плоской фото-карточки — процедурные
  SVG-купюры/монеты (вымышленный дизайн: абстрактный hex/web3-символ, золотые линии, без
  логотипов/портретов/номиналов). 3 слоя глубины (far/mid/near) с рандомизированными на
  уровне модуля (без SSR — Math.random() безопасен) позицией/масштабом/прозрачностью/blur/
  вращением/длительностью через CSS custom properties и один общий keyframe
  (`.hero-note`/`hero-note-drift`). Респонсивное количество через `tierForWidth()`
  (8-12/6-9/4-6/2-4 по брифу). `prefers-reduced-motion` → 1-3 статичных элемента без анимации.
  Область слева (где текст) сознательно исключена из диапазонов `left`.
- **Hero.tsx**: убран grid-коллаж, машина/деньги — абсолютно спозиционированные слои сцены;
  H1 переведён на `clamp()`-размер + разбит на 2 block-level `<div>` (не `<span>+<br/>`) —
  нашёл и исправил реальный баг при QA (см. ниже); бейдж — почти чёрный фон + тонкая изумрудная
  рамка; подзаголовок сужен до `max-w-[600px]`; CTA — новый класс `.btn-premium`
  (тёмный графитово-изумрудный корпус) вместо яркой хром-зелёной `.btn-metal`, стрелка едет по
  hover через `group-hover`; карточки статистики — `duration-300` на hover-тень.
- **Header.tsx**: `.nav-glass-top`/`.nav-glass-scrolled` (точные rgba/blur из брифа) вместо
  `color-mix(var(--color-bg))`; CTA тоже переведён на `.btn-premium`; тач-таргет мобильного
  меню увеличен (`p-2` → `p-2.5`).
- **Найден и исправлен реальный баг при QA**: `text-wrap: balance` на H1 не устранял "сиротское"
  слово в английской версии ("YOUR GATEWAY" / "TO"), пока строки жили в одном flow через
  `<br/>` — после разделения на два независимых block-level элемента с собственным `balance`
  проблема ушла (проверено скриншотом). Также найдено и исправлено: при `hidden md:block` для
  машины и одновременном `lg:48%`-контейнере на брейкпоинте 768-1023px возникал риск наложения
  машины на текст (посчитано вручную + проверено скриншотом на 768/820/1023) — машина возвращена
  на `lg:block` (1024px), как было в исходном дизайне до этой сессии (тот выбор оказался
  правильным изначально).

## Проверено
- `tsc --noEmit` и `npm run build` — чисто, без ошибок, оба раза после каждого большого блока
  правок.
- Playwright (реальный браузер, не эмуляция окна): 1920×1080, 1440×900, 1366×768, 1279×800,
  1100×800, 1024×768, 1023×900, 820×1180, 768×1024, 390×844, 375×812, 360×800, ultrawide
  2560×1440 — везде `scrollWidth === clientWidth` (нет горизонтального скролла), 0 ошибок в
  консоли/pageerror.
- RU/EN/VI на 1366 и 390 — самый длинный вариант (VI, "THẾ GIỚI WEB3 GAMING") красиво
  переносится, не обрезается.
- `prefers-reduced-motion: reduce` (реальный контекст Playwright, не CSS-заглушка) — только
  статичная композиция, без движения.
- Скроллнутое состояние навигации (`nav-glass-scrolled`) — визуально отличается от верхнего.
- Клавиатурная навigация: `Tab` до CTA → виден focus-visible ring (готовое правило
  `.chamfered:focus-visible` сработало без изменений); реферальная ссылка/`subId2` не
  затронуты.
- Инструменты для QA (`playwright@1.55`) поставлены через `npm install --no-save` — не попали
  в `package.json`/`package-lock.json` (проверено `git status` до/после).

## Не сделано / ограничения
- SSR/hydration-mismatch (п.18 брифа) — неприменимо, проект чистый Vite CSR SPA без SSR/Next.js.
- Lint/unit-тесты (п.6 брифа "запусти lint/typecheck/unit tests") — в проекте нет ни ESLint,
  ни тестового раннера (`package.json` без `lint`/`test` скриптов), только `tsc`. Не стал
  добавлять инфраструктуру тестирования самовольно — это отдельное решение, не часть текущего
  ТЗ про визуальный редизайн.
- Отражение автомобиля на асфальте отдельным mirror-слоем — намеренно не добавлено (см. выше,
  фото — цельная сцена, не cutout).
- AVIF-версии новых/существующих картинок — не создавались в этой сессии (не было изменений в
  самих файлах картинок, только в том, как встроены существующие).
- Не закоммичено в `main`, не запушено, не задеплоено — явного запроса на это не было.

устройстве) и явно попросить смержить+запушить+задеплоить, если всё устраивает.
