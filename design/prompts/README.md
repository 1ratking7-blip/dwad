# Промты для генерации изображений — luxury-редизайн ZHELEZO

Контекст: 2026-07-27, переход дефолтной темы лендинга (`data-theme='cyberpunk'`, значения
переменных в `Landing/src/index.css`) на премиальную luxury-эстетику (чёрный/графит/тёмный
металл/золото/изумрудный неон). Разработан совместно с GPT (`ask_gpt` MCP) как второй эксперт
по арт-дирекшену.

На момент написания у Claude Code нет инструмента генерации изображений — сайт на 100%
собран на CSS/SVG/Canvas (без растровых фото), см. компоненты `NightSkyline.tsx`,
`LuxuryCar.tsx`, `MetalCard.tsx`, `FloatingWealth.tsx`. Промты ниже — техзадание на будущее:
когда появятся реальные сгенерированные/стоковые изображения, их нужно положить в
`Landing/public/images/<имя>.webp` (+ `.avif` при возможности) и подключить через `<img>`
с `loading="lazy"`, `width`/`height` и `decoding="async"`, заменив соответствующий
CSS/SVG-плейсхолдер или дополнив его.

Промты — на английском (так генеративные модели точнее следуют композиции/деталям),
контекст и параметры формата — на русском.

**Обязательные ограничения для всех промтов**: без узнаваемых лого/торговых марок
(автомобильных брендов, платёжных систем, банков, казино), без реальных портретов,
серийных номеров купюр, номерных знаков.

Файлы:
- `01-hero-car.md` — главный автомобиль для hero (16:9 / 21:9).
- `02-metal-card.md` — металлическая банковская карта (4:5).
- `03-night-city.md` — фон ночного города (16:9).
- `04-money-coins.md` — деньги + золотые монеты, PNG с прозрачностью.
- `05-lifestyle-scene.md` — премиальная lifestyle-сцена (казино-фишки).
- `06-section-cards.md` — набор мини-сцен для карточек разделов (4:3, единый стиль).
